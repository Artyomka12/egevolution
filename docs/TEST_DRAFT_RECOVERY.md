## Причина HTTP 400 и пределы подтверждения

Текст «Обновите страницу и повторите запрос» выдавал обработчик `CSRFError`
в `core/tests_http.py` с HTTP 400 и `error.code=CSRF_FAILED`. Ошибка возникает
до выполнения создания/сохранения/публикации. До восстановления каталог был пуст:
частично созданных тестов не найдено.

В исходном `editor.js` токен извлекался из meta один раз, в `const csrf`,
при открытии страницы. Flask-WTF настроен со стандартным сроком 3600 секунд.
Обновления токена не было. После часа редактирования токен не проходил проверку,
а интерфейс предлагал перезагрузить страницу с несохранённым содержимым.

На настоящих маршрутах и Flask-WTF, с авторизованной фиктивной сессией,
воспроизведены HTTP 400, `CSRF_FAILED`, тот же исходный текст ответа и серверный
лог `The CSRF token has expired.` Ни одной записи теста при отказе не появилось.

Старый ответ конкретного запроса преподавателя не сохранился: Network включили
после ошибок. Поэтому отклонение CSRF установлено по точному обработчику сообщения,
а истечение срока подтверждено воспроизведением; отличить его от другой причины
CSRF в том историческом запросе без журнала невозможно. Открытую вкладку не
обновляли и новые запросы сохранения из неё не отправляли. Доступ computer-use
к Яндекс Браузеру был остановлен инструментом из-за неподдерживаемой политики URL;
дальнейшая работа выполнялась через локальные файлы и изолированные проверки.

## Исправление

- Новый `GET /api/admin/tests/csrf` проверяет действующий аккаунт и права
  администратора через штатный guard. Требуется `X-CSRF-Refresh: 1`;
  ответ `private, no-store`, без CORS. Токен подписывается для текущей сессии.
- Редактор после подтверждённого HTTP 400 `CSRF_FAILED` один раз получает
  свежий токен и повторяет тот же запрос без перезагрузки и потери ввода.
  Тело, CAS-ревизия и ключ идемпотентности сохраняются, в том числе после
  неизвестного результата и для FormData. При смене аккаунта повтор запрещён.
- При повторном отказе/ошибке обновления токена цикл ограничен; данные редактора
  остаются на странице. CSRF, срок 3600 секунд, авторизация и идемпотентность
  не отключались. Ответ содержит безопасный код `csrf_reason` без токенов.

Код изменён в `static/js/admin/tests/editor.js`, `features/tests/routes_admin.py`,
`core/tests_http.py`, `templates/admin/tests/editor.html`.
Добавлены `scripts/recover_test_draft.py`, `tests/test_tests_csrf_refresh.py`,
`tests/test_tests_recovery.py`; расширен `tests/test_tests_admin_requests.cjs`.
Учебные данные изменены только в `tests_content/catalog.json` и новом
`tests_content/test_611958516266134/material.json`; в SQLite добавлены ID теста,
