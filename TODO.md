## Целостность данных (из SQL-аудита 2026-06-16)

- [x] **D-1: `delete_user()` не удаляет связанные записи** — исправлено в v1.2.6.
  `POST /admin/delete_user/<user_id>` теперь удаляет все данные пользователя из 7 таблиц
  в правильном порядке: `user_task_answers` → `user_results` → `user_lesson_progress` →
  `user_theory_progress` → `user_lesson_access` → `user_theory_access` → `users` (последней).

- [x] **D-2: `task_id` из JSON не валидируется как `int`** — исправлено в v1.3.0.
  Строгая проверка типов: `int` и digit-строка `"5"` принимаются; `float`, `bool`,
  `null`, `list`, `object` отклоняются с 400 до записи файлов на диск.
  Атомарность восстановлена: при ошибке папка варианта не создаётся. 9/9 сценариев проверены.

- [x] **D-3: `str(e)` в двух admin-only маршрутах** — исправлено в v1.3.0.
  `/api/theory/save` и `/api/variants/save` возвращают generic-сообщение при исключении.
  `str(e)` не раскрывается даже администратору.
